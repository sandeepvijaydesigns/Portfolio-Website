Portfolio system

Sandeep N Vijay, Product & Visual Designer. A monochrome interface, so the work supplies the color.

Principles

Contrast is the color

Hierarchy comes from ink against paper. Project images are the only color on the page.

Red is rare

The accent marks errors, one key action or a single highlight. Never a fill for large areas.

Hard edges, round corners

Thick outlines and hard shadows, softened by pill and 14px radii.

Shape beats color

States use fill, stripes and icons so meaning survives without color.

Token architecture

A token is a named design decision stored as a variable, such as a color or a spacing step. This system uses three tiers, and each tier only points to the one below it.

Tier 1

Primitive tokens

Raw values with no meaning attached, named by what they are, like --gray-600: #5A5A5A. They are the palette and scale to pick from. Components never use them directly.

Tier 2

Semantic tokens

Named by purpose and aliased to a primitive. --muted means secondary text and points to --gray-600 in light and --gray-400 in dark. Components use these.

Tier 3

Component tokens

Optional and specific to one component, like --btn-bg: var(--fg). Use them when a component needs its own override without changing the shared meaning.

The chain

primitive --gray-600: #5A5A5A; semantic --muted: var(--gray-600); /* dark: var(--gray-400) */ component .card p { color: var(--muted); }

Spacing steps (s1 to s9) are primitives. Radius, border and shadow (--r, --bd, --sh) are semantic because they describe use, not a raw size.

Rules

Use semantic only

Components reference --fg or --muted, never a hex value or a primitive.

Dark mode remaps

Switch themes by pointing semantic tokens at different primitives. No component changes.

Rebrand at the base

Change a primitive and everything that depends on it updates.

Name by purpose

--muted survives a redesign. --light-grey does not.

Foundations

Spacing (4px base)

Shape, borders and elevation

Radius

--r 14px for cards and tiles, 12px for inputs, 999px for buttons and badges.

Border

--bd 2px solid fg on every interactive or containing element.

Elevation

No blur. Hard offset shadow 4px 4px 0 in ink; accent shadow for errors.

Motion

150ms ease for hover and state. Respect reduced motion.
